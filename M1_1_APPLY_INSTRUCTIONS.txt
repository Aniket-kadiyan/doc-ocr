WHAT CHANGED
------------
1. Adds one validated RuntimeConfig contract for current and future settings.
2. Keeps OCR_HOST, OCR_PORT, OCR_RELOAD, OCR_DEVICE and the existing backend
   launch commands compatible.
3. Changes the documented/default UI port from 3000 to 3002.
4. Adds configuration placeholders for the later database, logging and HTTPS
   milestones. M1.1 does not activate database migration, file logging or TLS.
5. Rejects malformed ports, booleans, log levels and CORS origins at startup.
6. Prevents DATABASE_URL credentials from appearing in RuntimeConfig repr or
   the public configuration summary.


LOCAL .env.local
----------------
Your existing .env.local is not overwritten by this package.

To use port 3002 now, change or add:

QTRACX_ENV=development
PORT=3002

Your existing backend and GPU values remain valid, for example:

OCR_HOST=127.0.0.1
OCR_PORT=8000
OCR_DEVICE=gpu:0
OCR_RELOAD=false

Do not add DATABASE_URL or enable HTTPS yet unless you are only reserving the
values. Those features are implemented in later milestones.
