RUNTIME CHECK
-------------
Start the backend normally. In another PowerShell window run:

$response = Invoke-WebRequest http://127.0.0.1:8000/health
$response.StatusCode
$response.Headers["X-Request-ID"]
Get-Content .\backend\logs\qtracx-backend.log -Tail 20

Expected:

  StatusCode is 200.
  X-Request-ID contains a UUID.
  The log contains backend_starting and backend_ready events.

Run an Auto Balloon scan and check the log again. Events for that scan should
share one job_id and include scan_job_queued, scan_job_started, scan_job_stage,
and a terminal scan_job_completed, scan_job_failed, or scan_job_cancelled event.
