Persistent selected-review highlight
====================================

Branch: MVP1
Expected base commit: e3a8e96e3d21b33d33a48c62776239aabff1a05d

This ZIP supersedes the earlier selected-review-highlight ZIP. It contains the
same visual highlight changes plus the persistent-selection adjustment.

Copy the included src directory over the repository's src directory.

Resulting behavior:
- Selecting a review value opens the review popup and highlights its geometry.
- Closing the popup leaves that review value highlighted.
- Accepting or ignoring the value removes its review highlight.
- Selecting another review value transfers the highlight to it.
- Selecting a normal balloon/value or clicking blank drawing space clears the
  review highlight.

Suggested validation:
  npm run typecheck
  npm run test:frontend
  npm run lint
  npm run build

Suggested commit message:
  fix(review): preserve highlight after closing review popup
