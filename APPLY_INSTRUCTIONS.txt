QTracX M1.2 Windows logging-test correction
============================================

Branch
------
Remain on: Configuration-and-logging

How to apply
------------
Copy the backend folder from this package over the repository root.
Allow Windows to replace:

  backend/test_app_logging.py

This is an incremental correction for the previously supplied M1.2 package.
Do not revert the earlier M1.2 files.

What it fixes
-------------
The three logging tests now close the RotatingFileHandler before their
TemporaryDirectory is removed. Windows locks open log files, which caused
WinError 32 even though the actual logging assertions succeeded.

Validation
----------
From doc-ocr/backend:

  .\.venv-gpu\Scripts\python.exe -m unittest -v `
    test_config_env.py test_app_logging.py test_ocr_runtime.py

Expected result: Ran 18 tests ... OK

Then, from the repository root:

  npm run verify

The six test_symbol_markers.py failures shown in the supplied output are
separate from this logging change and are not modified by this package.

Commit
------
Do not create a separate commit for this correction if the M1.2 commit has not
yet been made. Include it in:

  feat(logging): add structured backend diagnostics
