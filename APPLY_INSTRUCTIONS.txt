Run tests on Windows
--------------------

  .\.venv-gpu\Scripts\python.exe -m unittest -v test_source_images.py

Run the backend
---------------
From doc-ocr/backend:

  $env:CUDA_VISIBLE_DEVICES="0"
  $env:OCR_DEVICE="gpu:0"
  $env:OCR_RELOAD="false"
  .\.venv-gpu\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000

The backend must be running while opening or previewing a TIFF file.
