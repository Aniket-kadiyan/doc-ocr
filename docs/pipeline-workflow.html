Ink to Balloons

How one selection on an engineering drawing becomes a list of balloon-labeled dimensions: the stages of OcrPipeline.segment(), and the recovery path for callouts lettered along a leader line.

PaddleOCR 3.7 Python 3.12 backend/ocr_pipeline.py 178 tests

The main path

A CAD sheet is mostly geometry. The dimension text is a small share of the ink, it sits at every orientation, and one callout is often detected as three separate fragments. So the pipeline detects lines of text, decides which fragments belong to the same callout, and only then reads each callout on its own crop.

Inside one callout

Reading a crop is two streams that meet. One puts the crop through several preprocessing variants and votes on the digits. The other looks for the symbols directly in the pixels. A diameter mark is found by topology: one ink shape enclosing two similar holes, which is a ring cut by a slash. A digit never produces that, which is what separates a real Ø from a leading 0, 4 or 8.

Callouts written along a leader

A chamfer or a fit callout is lettered along its leader line, at whatever angle that line runs. Both detector passes read horizontal text, so these are missed. The recovery path levels the text and reads it again, and the only hard part is knowing the angle.

The original answer was a vote over the drawing's diagonal ink. That vote is diluted by everything else in the selection, so it fires on a zoomed crop and goes silent on a full sheet, which is exactly when a user is least likely to notice a missing dimension.

Sheet selection 0.130 Under the 0.15 bar. Silent.
Full page 0.030 Nowhere near it. Silent.

Where the thresholds live

Most tuning in this pipeline is one of two mistakes: judging a size as a fraction of the crop, which changes when the user zooms, or judging a read by its length, which rewards garbled text for being long. The values below are the ones that decide outcomes.

DecisionValueWhat it protects
Diameter from ring topology 2 holes A slashed ring has two; digits 0, 4 and 8 have one, and 8's two sit across the reading axis.
Cluster size cap 3 × median box Keeps a chain of neighbours from fusing, without using a fraction of the crop.
Oversized cluster re-split 6 × text scale A normal callout in a small selection is no longer shredded into fragments.
Same-ink angled reads 0.50 overlap Measured on rotated rectangles. Parallel leaders score near zero; the same text twice scores high.
Complete clusters merging 0.60 overlap Two finished values need near containment to fuse; a fragment still rejoins at 0.25.
Angled read ranking symbols − junk Resolved marks beat length, so a longer garbled read cannot outrank a clean one.
Leader line minimum 5% of the long edge Long enough to be a leader, and near-axis lines are skipped as dimension lines.
