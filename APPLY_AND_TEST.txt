What this changes
-----------------
- Accepts stacked tolerance bounds read on one line, including:
  - Ø33 +0.012 0
  - Ø33 -0.05 -0.10
  - +0.012 0
  - +0.05 -0.05
- Parses the first stacked value as the upper bound and the second as the
  lower bound instead of treating the first value as a signed nominal.
- Keeps single-bound tolerances such as +0.1 and -0.5 unchanged.
- Accepts the tolerance-zone and datum portion of feature-control frames:
  - Ø0.02A
  - Ø0.1 A B
  - Ø0.3 A B C
  - Ø0.02Ⓜ A B
- Records these FCF values as a complete GD&T parse with the tolerance zone,
  optional material-condition glyph, and datum sequence retained separately.
- Removes an orphan closing parenthesis only when the remaining whole string
  is a complete engineering value. Balanced reference and dual-unit brackets
  remain unchanged.

Safety guards
-------------
- Two unsigned numbers such as 33 0.5 remain invalid.
- A datum sequence requires Ø and 1–3 valid uppercase datum letters.
- Values such as 25 A, 0.5 m, lowercase datum text, and I/O/Q datum letters
  remain invalid.
- Mixed text such as ZONE A 25) is not repaired into a value.
