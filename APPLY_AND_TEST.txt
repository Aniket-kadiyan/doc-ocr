QTracX selective integration SI-2.4
==================================

Purpose
-------
Correct the visual plus/minus detector without changing OCR text, native PDF
text extraction, dimension composition, page filtering, or export.

The previous template used the opposite polarity from the processed drawing
ink and scored the padded background. This package:

* matches the template polarity to the processed image;
* crops matching to the detected ink rather than the white page border;
* uses template sizes relative to the ink height;
* raises the operating threshold to the calibrated high-precision value 0.60;
* adds real positive and negative CAD crops as regression fixtures.

Apply on Windows PowerShell
---------------------------
1. Open the doc-ocr repository root in PowerShell.
2. Confirm you are on selective-integration and review local state:

   git status --short --branch

3. Extract this ZIP over the repository root:

   Expand-Archive -Path "<download-folder>\QTracX_SI2_4_plus_minus_vision.zip" `
     -DestinationPath . -Force

4. Review this milestone only:

   git diff -- backend/symbol_vision.py backend/debug_steps_catalog.py
   git status --short backend/test_plus_minus_vision.py backend/benchmarks/fixtures/plus_minus

Tests
-----
Run from doc-ocr\backend using the GPU environment, which contains OpenCV:

   .\.venv-gpu\Scripts\python.exe -m pytest -q `
     test_plus_minus_vision.py

The dedicated suite should execute the synthetic checks and all 14 real crop
fixtures. It must not be skipped because cv2 is required for this milestone.

Then run the adjacent OCR regressions:

   .\.venv-gpu\Scripts\python.exe -m pytest -q `
     test_plus_minus_vision.py `
     test_phi_evidence.py `
     test_compose_minus.py `
     test_page_candidate_recovery.py `
     test_ocr_runtime.py
