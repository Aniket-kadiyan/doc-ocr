Feature-control-frame parsing and compartment validation

Base branch verified:
  selective-integration @ 07ff5c3

What this package adds
----------------------
1. backend/fcf_parse.py
   Detects ruled feature-control frames, separates composite-frame segments,
   splits compartments, and returns structured GD&T data rather than a
   flattened OCR string.

2. backend/benchmarks/gdt_synthetic.py
   Deterministic synthetic drawing/frame generation with exact ground truth.
   It is test support and a regression baseline—not a claim of real-world
   accuracy.

3. backend/test_fcf_parse.py
   Covers frame geometry, compartment splitting, rule erasure, composite
   frames, tolerance/modifier parsing, datum precedence, schema validation,
   visual diameter-zone recovery, OCR failure isolation, and false-frame
   rejection.

Structured output
-----------------
Each parsed frame keeps separate fields for:
- geometric characteristic and its confidence/status
- tolerance value
- diametral-zone marker
- material-condition modifier
- other modifiers
- ordered datum references
- composite segment identity
- original compartment text and bounding boxes
- warnings and evidence

Safety behavior
---------------
- Missing information distinguishes absent, unreadable, and not-applicable.
- An OCR failure in one compartment does not remove the complete frame.
- Ambiguous characteristic symbols retain the frame for review.
- Datum precedence follows physical compartment order, even when one datum
  cannot be read.
- No drawing unit is invented; the unit remains "drawing_unit".
- Boxes without a geometric characteristic are not published as valid FCFs.
- Composite controls retain their segment relationship.

Scope boundary
--------------
This milestone adds the standalone FCF parser only. It does NOT invoke it from
production page scanning, alter the auto-ballooning pipeline, expose new API
fields, or change the UI/review/export flows. Those connections remain a
separate controlled integration milestone.

How to apply
------------
1. Confirm you are on selective-integration and have no unrelated local
   changes that these paths would overwrite.
2. Extract this ZIP into the doc-ocr repository root, preserving paths.
3. Review the three added files.
