QTracX selective integration SI-2.3
==================================

Purpose
-------
Prevent nearby DETAIL, SECTION, and SCALE captions from hiding drawing
dimensions. Direct caption text and genuine split-caption fragments remain
excluded. Valid values continue to the balloon workflow; malformed numeric
values continue to Reviews through the existing invalid-value disposition.

Apply on Windows PowerShell
---------------------------
1. Open the doc-ocr repository root in PowerShell.
2. Confirm you are on selective-integration and have no uncommitted changes:

   git status --short --branch

3. Extract this ZIP over the repository root and allow the two files above to
   be replaced. From PowerShell, for example:

   Expand-Archive -Path "<download-folder>\QTracX_SI2_3_caption_proximity_safety.zip" `
     -DestinationPath . -Force

4. Review the exact changes:

   git diff -- backend/page_value_filters.py backend/test_page_value_filters.py
