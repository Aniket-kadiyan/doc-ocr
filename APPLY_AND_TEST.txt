What this package adds
----------------------
1. backend/gdt_detect.py
   A standalone hybrid GD&T glyph detector using aligned procedural-template
   comparison, contour/topology evidence, optional OCR corroboration, and
   explicit confidence/ambiguity handling.

2. backend/gdt_config.py
   External GDT_* settings for confidence thresholds, glyph size bounds,
   duplicate merging, page tiling, and feature-control-frame geometry.

3. backend/benchmarks/fixtures/glyphs/
   Small real glyph crops from drawings. These ensure the detector is tested
   against actual drawing symbols rather than only templates generated from
   the same code used for matching.

4. Tests
   Detector decisions, ambiguity handling, template matching, degradation
   safety, real-glyph recognition, coordinate transforms, duplicate merging,
   serialization, and configuration loading/caching.

Safety behavior
---------------
- A close rival produces status="ambiguous" instead of a confident guess.
- A mark below the confidence floor remains "unknown" with evidence.
- Symbols sharing identical artwork remain ambiguous.
- Tiny or unreadable circled modifiers are downgraded rather than promoted.
- Retired and standards-specific symbols retain warnings.
- Non-visual engineering concepts cannot be reported as detected glyphs.

Scope boundary
--------------
This milestone adds and tests the standalone detector only. It does NOT call
the detector from page scanning or auto-ballooning, and it does not change the
API, UI, review list, persisted checksheet, or export output. Production-path
integration will be a separate milestone with explicit review routing.

How to apply
------------
1. Confirm you are on the selective-integration branch and have no unrelated
   local changes that these paths would overwrite.
2. Extract this ZIP into the doc-ocr repository root, preserving paths.
3. Review the two modules, two test files, and glyph fixture directory.
