QTracX selective integration SI-3.1
==================================

Purpose
-------
Replace broad GD&T keyword matching with guarded textual GD&T recognition.

The previous classifier treated a GD&T word by itself as sufficient evidence.
That could label measurement notes such as ROUNDNESS(2PT./180)50µm MAX. or
SQUARENESS WITH FACE 50µm MAX. as GD&T inspection controls.

The new text recognizer accepts a result only when the text has the shape of a
callout: a short unambiguous glyph callout, a pipe-delimited frame, or a GD&T
name followed by a tolerance value. Prose, measurement specifications, and
ambiguous glyphs are refused. Accepted results carry their source text,
confidence, evidence, value, datum sequence, and diametral-zone flag.

Compatibility boundary
----------------------
* Existing geometry-backed feature-control frames remain authoritative.
* Native PDF text and OCR text are not replaced or modified.
* No changes are made to scanning, image detection, persistence, or export.
* The extra gdt_text result field is additive and appears only when this rule
  accepts a textual GD&T callout.

Apply on Windows PowerShell
---------------------------
1. Open the doc-ocr repository root in PowerShell.
2. Confirm you are on selective-integration and review local state:

   git status --short --branch

3. Extract this ZIP over the repository root:

   Expand-Archive -Path "<download-folder>\QTracX_SI3_1_guarded_textual_gdt.zip" `
     -DestinationPath . -Force

4. Review the milestone:

   git diff -- backend/gdt_text.py backend/feature_classifier.py backend/feature_rules.py
   git status --short backend/test_gdt_text.py backend/test_feature_classifier.py backend/test_feature_rules.py
