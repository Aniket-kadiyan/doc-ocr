QTracX selective integration — SI-3.2
GD&T symbol registry and procedural template foundation

Base branch verified:
  selective-integration @ 5c4d254

What this package adds
----------------------
1. backend/gdt_registry.py
   One authoritative, ambiguity-aware registry for GD&T, datum,
   material-condition, dimensioning, manufacturing, and frame symbols.

2. backend/gdt_templates.py
   Procedurally rendered OpenCV templates for symbols that have reliable
   geometric artwork. Templates are generated in code; no binary artwork or
   model files are added.

3. backend/gdt_text.py
   SI-3.1 textual GD&T now resolves stable symbol IDs through the registry
   instead of maintaining a second hard-coded ID map. Existing Runout and
   Profile family fallbacks are preserved.

4. Tests
   Registry integrity, ambiguity handling, standards metadata, template
   coverage, rendering polarity, caching, scale selection, and contact-sheet
   construction.

Scope boundary
--------------
This milestone does NOT enable page-level graphical GD&T detection and does
not change the auto-ballooning workflow, API payloads, UI, or exports. It is
the tested foundation for the next graphical-detection milestone.

How to apply
------------
1. Confirm you are on the selective-integration branch and have no unrelated
   local changes that these files would overwrite.
2. Extract this ZIP into the doc-ocr repository root, preserving paths.
3. Review the five changed/added backend files.
